# **App Name**: CP-Pharma Valentine's Shop

## Core Features:

- Product Grid Display: Display all 39 Valentine's packages in a responsive grid layout on the home page.
- Product Details Page: Show detailed information for each package, including images, description, contents, price, and stock status.
- Quantity Selection: Allow users to select the quantity of each package they want to purchase, up to the available stock.
- Checkout Flow with Order Summary: Implement a multi-step checkout process that includes an order summary, purchase confirmation, fulfillment method selection, and contact information collection.
- Order Simulation and Persistence: Simulate an API call for order placement and save order details to localStorage for persistence.
- Order success Confirmation Page: Confirmation screen with complete order information
- Input Validation Tool: Uses an AI tool to provide validation for form input, checking input against known data structures and rules

## Style Guidelines:

- Primary color: Soft pink (#FFB6C1) to evoke a romantic Valentine's theme.
- Background color: Light pink (#F8E8EE) for a subtle, premium feel.
- Accent color: Rose gold (#B76E79) for highlighting important elements such as CTAs.
- Body and headline font: 'Alegreya', a serif font, to evoke an elegant and contemporary feeling.
- Use heart-themed or love-related icons to enhance the Valentine's theme.
- Maintain a clean, mobile-first layout with ample spacing and accessible labels for a smooth user experience.
- Incorporate subtle animations and transitions to create a visually engaging experience, like fading effects or slight scaling on hover.
